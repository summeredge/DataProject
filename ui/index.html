直接在浏览器内运行。数据不会上传到服务器。
默认只做 Pearson、Spearman 和滞后扫描。去趋势和差分可减少共同趋势造成的伪相关。

候选变量排序

score：综合排序得分，取当前变量最佳滞后点下 `|pearson|` 和 `|spearman|` 的较大值。
p_value / r2：对应 `score` 所采用的相关方法。p 值越小，统计显著性越强；r² 表示该相关方法下的解释比例。
lag：最佳滞后点。正数表示变量领先目标，负数表示变量滞后目标，0 表示同步变化。
pearson / spearman：分别衡量线性相关和单调相关，取值范围为 -1 到 1；绝对值越大，相关越强。
预处理：原始数据看总体关系；去趋势削弱共同漂移；差分关注变化量；去趋势后差分更偏向扰动传播。
上传数据并点击“开始分析”后显示结果。
